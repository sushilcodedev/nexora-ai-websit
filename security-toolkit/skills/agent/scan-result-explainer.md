# Skill: Scanner Output Explainer
Explain imported Nuclei, ZAP, httpx, Subfinder or Katana records to a beginner.
- Treat scanner results as leads, not proof.
- Explain template/rule names, severity and confidence where supplied.
- Asset discovery and HTTP metadata are informational, not vulnerabilities by themselves.
- Point out false-positive possibilities and missing context.
- Recommend only non-destructive manual review in a permitted lab.
- Never execute a scanner or follow URLs.

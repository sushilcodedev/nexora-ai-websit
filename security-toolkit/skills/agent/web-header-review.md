# Skill: HTTP Security Header Review
Review only pasted HTTP response headers.
- Explain CSP, HSTS, X-Content-Type-Options, Referrer-Policy, Permissions-Policy, and framing controls.
- Explain context and browser support; avoid treating every missing header as a vulnerability.
- Distinguish HTTP from HTTPS and note HEAD versus GET differences.
- Suggest safe configuration examples only when the server/framework context is known.
- Never request a live target or claim you fetched it.
Output: Header table, practical risk, confidence, configuration guidance, validation checklist.

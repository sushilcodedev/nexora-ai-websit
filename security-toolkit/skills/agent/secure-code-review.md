# Skill: Defensive Code Review
Review source code provided by the user for defensive security issues.
- Analyze only the pasted or uploaded code; do not execute it or fetch dependencies.
- Identify risky data flows, validation gaps, authentication/authorization checks, secrets, unsafe deserialization, injection, and insecure defaults.
- Quote only short relevant snippets and explain impact and confidence.
- Recommend minimal safe fixes and regression tests.
- Never turn the review into exploit instructions against a live service.

# Skill: Responsible Disclosure Report Writer
Turn user-supplied, redacted, authorized evidence into a clear report.
- Include title, asset, severity rationale, summary, impact, prerequisites, reproducible steps, evidence, remediation and references.
- Do not exaggerate impact, fabricate proof, or include other people's data.
- Mark unverified claims as suspected.
- Remind the user to re-check program scope, exclusions and disclosure rules before submission.
Output a professional Markdown report.

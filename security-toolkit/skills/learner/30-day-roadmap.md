# NEXORA Bug Bounty: 30-Day Beginner Roadmap

Daily target: 60–120 minutes. Cost: ₹0. Practice only PortSwigger labs, OWASP Juice Shop running locally, or explicitly authorized targets.

## Week 1 — Web foundations
- Day 1: HTTP request/response, methods, status codes, headers.
- Day 2: URLs, query parameters, path segments, encoding.
- Day 3: Cookies, sessions, authentication vs authorization.
- Day 4: Browser DevTools Network tab.
- Day 5: Burp Suite Community basics using a local lab.
- Day 6: HTML forms, JavaScript basics, same-origin policy.
- Day 7: Review and write notes using lab-notes-template.md.

## Week 2 — Core vulnerability classes
- Day 8: Access control concepts and authorization checks.
- Day 9: IDOR / broken object-level authorization in a lab.
- Day 10: Reflected and stored XSS concepts in a lab.
- Day 11: SQL injection concepts in a lab.
- Day 12: CSRF and anti-CSRF defenses.
- Day 13: Authentication and session management weaknesses.
- Day 14: Explain each issue, impact, and remediation in your own words.

## Week 3 — Methodology
- Day 15: Read the OWASP Web Security Testing Guide overview.
- Day 16: Learn program scope, exclusions, and safe harbor wording.
- Day 17: Passive asset inventory for a lab or owned domain.
- Day 18: Security headers and TLS basics.
- Day 19: API basics, JSON, and authorization boundaries.
- Day 20: Business logic flaws using intentionally vulnerable labs.
- Day 21: Practice a minimal, reproducible report.

## Week 4 — Practice and reporting
- Day 22: Complete two beginner PortSwigger labs.
- Day 23: Complete two more labs and record evidence safely.
- Day 24: Re-test your understanding; distinguish false positives.
- Day 25: Draft one report from a completed lab.
- Day 26: Read one public program policy; do not test until scope is understood.
- Day 27: Select a beginner-friendly program with clear scope and safe harbor.
- Day 28: Plan a low-impact test checklist; no automated scan by default.
- Day 29: Review findings and remove secrets/personal data from notes.
- Day 30: Self-assessment and next-month learning plan.

## Free resources
- PortSwigger Web Security Academy: https://portswigger.net/web-security
- OWASP Web Security Testing Guide: https://owasp.org/www-project-web-security-testing-guide/
- OWASP Juice Shop: https://owasp.org/www-project-juice-shop/
- Burp Suite Community: https://portswigger.net/burp/communitydownload
- OWASP ZAP: https://www.zaproxy.org/

## Completion criteria
By day 30, aim to explain the HTTP lifecycle, use a proxy in a lab, complete beginner labs, identify scope boundaries, and write one clear report. A bounty or income is not guaranteed.

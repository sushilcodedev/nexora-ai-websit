# NEXORA — First-client outreach messages

Use these as starting drafts. Personalize each message and contact only businesses through publicly listed business contact channels. Do not mass-spam, exaggerate risk, claim you found vulnerabilities, or run checks before permission.

## Short email
**Subject:** A simple website security-header review for [Business]

Hello [Name],

I’m reaching out from NEXORA AI. We are piloting a small, non-intrusive website security hygiene review for businesses.

The review checks selected HTTP security response headers on one exact URL, then provides a short, plain-English report with practical recommendations and limitations. It is not a penetration test or a security certification.

Our introductory pilot price is ₹499 for one website. We only begin after the website owner or authorized representative approves the exact URL and limited test in writing.

Would this be useful for your website? If not, no problem.

Regards,  
NEXORA AI

## If someone asks "Can you hack/test my website?"
Thanks for asking. Our current service is limited to one approved HTTP HEAD request and a review of selected response headers. We do not currently offer penetration testing, exploitation, login testing, crawling, or vulnerability scanning. If you need a full security assessment, please engage a qualified security professional.

## If someone asks for proof
Share only a sample report from your own lab or a system you own. Never disclose another client's report, domain, evidence, contact details, or findings without explicit written permission.

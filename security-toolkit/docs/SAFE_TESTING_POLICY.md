# Safe Testing Policy

NEXORA Security Toolkit is an educational helper, not authorization to test any system.

Before testing:
1. Obtain explicit written permission or use a designated training lab.
2. Confirm exact hostnames, paths, accounts, test windows, and excluded assets.
3. Read the current program policy, safe-harbor language, rate limits, and prohibited techniques.
4. Use test accounts and synthetic data where allowed.
5. Start with low-impact checks and stop if behavior is unexpected.

Never scan arbitrary public IP ranges or domains; access, copy, or disclose another person's data; brute-force credentials or bypass rate limits; conduct denial-of-service, destructive, persistence, or social-engineering tests; exploit beyond the minimum proof; or continue after authorization is withdrawn.

A scope entry in the local JSON file is only a reminder created by the user. It is not proof of permission and does not override a program's live policy.
